# Reliability Rubric
Evaluate reliability using this rubric: safe failure/degradation, idempotency, correct timeouts/retries/backoff; explicit error handling; state consistency/atomicity; concurrency correctness; dependency isolation; resource limits/load shedding; boundary validation; actionable logs; SLO metrics; traces/diagnosability; integration tests for failure modes; invariant/fuzz tests; failure injection readiness; and safe deploy/rollback/migrations. Score 0–3 each and propose prioritized fixes that reduce outage and data-corruption risk.
